The goal of Plasmosome is to be widely used and successful. Everything else here exists to serve
that.

For that we should have a distribution setup, documentation, a website, and whatever other
artifacts help people use, update and contribute to it. Use, update and contribute are three
different things, not one: getting a first version running is not the same as moving an existing
one forward, and neither is the same as sending something back. The people I mean are both new
users and existing ones — an artifact that only serves arrival leaves everyone already here
unserved.

Contribution has two surfaces and they are separate. Someone may want to contribute to the
Plasmosome codebase itself. Someone else may want to contribute to the plasmid plugin ecosystems
and never touch the kernel. Both should be possible, and neither should be the price of the other.

Nothing in this repository currently says that being installable or contributable is wanted. The
publishing spec, 007, hangs off 002 — a testing intent — through a subordinate clause, because
there was nowhere else to attach it. This is what it should descend from.

How any of this gets built is not decided here. What the distribution setup is made of, what the
website is, and what the documentation covers are all questions for later.
